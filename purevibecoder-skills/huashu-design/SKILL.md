# Huashu Design 教程：用 AI 做出大厂级设计

> 本教程目标：帮助任何人掌握用 AI 生成高保真设计的完整流程

---

## 一、Huashu Design 是什么

Huashu Design 是由花叔（@AlchainHust）开发的开源 AI 设计 Skill。

**核心定位：**
- 在你的 Agent 里打一句话，拿回一份能交付的设计
- 终端 AI 设计利器，无需打开任何图形界面
- 3 到 30 分钟，交付产品发布动画、可点击的 App 原型、可编辑的 PPT、印刷级信息图

**安装：**
```bash
npx skills add alchaincyf/huashu-design
```

**支持的 Agent：** Claude Code、Cursor、Codex、OpenClaw、Hermes

---

## 二、能做什么

| 能力 | 交付物 | 典型耗时 |
|---|---|---|
| PPT 生成 | 可编辑的 HTML/PPTX 幻灯片 | 3-10 分钟 |
| App 原型 | 可点击的高保真原型（HTML） | 5-15 分钟 |
| 信息图 | 印刷级 PNG/SVG 图表 | 5-10 分钟 |
| 动画 | 产品发布动效（Lottie/MP4） | 10-30 分钟 |
| 时间轴 | 设计精美的时间轴可视化 | 5-10 分钟 |

---

## 三、安装与使用

### 安装

```bash
npx skills add alchaincyf/huashu-design
```

### 基础用法

直接告诉 Agent 你要什么：

```
"帮我做一个 Neuma Agent 的投融资 one-pager，要电影海报级的视觉冲击力，
深色背景，突出 AI × Biohacking 的科技感"
```

Agent 会自动调用 Huashu Design Skill，输出可直接交付的设计文件。
