# GPT-image-2 出图 + 分享帖 完整 Skill

## 触发条件

当用户需要用 API Mart GPT-image-2 出图、做社交媒体配图、分享提示词、生成品牌视觉，或需要从 X/Twitter 抓取优质 prompt 教学内容时自动触发。

## Step 1：提示词编写框架

### 核心结构

```
[任务目标] + [核心构图] + [细节密度] + [风格] + [色彩] + [负面词] + [质量修饰]
```

### 各模块写法

**任务目标**
- 明确最终用途（profile 配图、品牌海报、概念图）
- 例："收藏版史诗叙事海报，作为个人 profile 更新帖配图"

**核心构图**
- 主体、视角、占比、位置
- 例："巨大的东方男性侧脸剪影作为唯一主轮廓，人物占画面约 60%"

**细节密度**
- 明确要包含和排除的元素
- 例："只保留少数最有辨识度的叙事元素，以静态、克制为主"
- 负面例："不要杂乱，不要硬拼贴，不要模板化背景"

**风格**
- 融合多种高级视觉风格
- 例："电影海报级叙事设计 + 梦幻水彩插画 + 双重曝光联想"

**色彩**
- 严格给出主色和局部点缀
- 例："只允许深靛蓝、墨灰、月白、少量香槟金"

**负面要求**
- 必须明确列出不要出现的内容
- 例："不要古装长发美男，不要偶像剧感，不要廉价拼贴"

**质量修饰**
- 例："柔和空气透视、轻雾化过渡、纸张颗粒、边缘飞白"

### Prompt 关键技巧

1. **人设映射不写复刻照片**，写精神肖像，明确视觉锚点
2. **高级克制**：元素越少越值钱，宁缺毋滥
3. **色温统一**：给 AI 一个主色盘，不让它自由发挥
4. **负面词越具体越好**：写"不要古装长发"比"不要古偶感"更有效
5. **叙事密度分层**：远景主体 + 中景叙事 + 近景细节

## Step 2：生图脚本

脚本位置：`scripts/generate-and-share.py`

### 基本用法

```bash
cd ~/.hermes/skills/creative/gpt-image-2-workflow
python3 scripts/generate-and-share.py "你的提示词" [比例] [文件名前缀] [分辨率档] [质量]
```

参数说明：

| 位置 | 参数 | 默认值 | 说明 |
|------|------|--------|------|
| 1 | 提示词 | 必填 | 完整描述，建议加引号 |
| 2 | 比例 | `4:5` | 见下表 |
| 3 | 文件名前缀 | `gen` | 用于文件命名 |
| 4 | **分辨率档** | **`2k`** | `1k`/`2k`/`4k`，**默认 2k，绝不用 1k** |
| 5 | 质量 | `high` | `low`/`medium`/`high`/`ultra` |

### 分辨率档位规则（重要）

| 档位 | 最大边基准 | 适用场景 | 说明 |
|------|-----------|---------|------|
| `1k` | 1024 | 省钱日常 | **不推荐用于配图/海报** |
| `2k` | 2048 | 海报、高清配图 | **默认档**，总像素充裕，支持全部 13 种比例 |
| `4k` | 3840 | 超高清印刷、大幅面 | 受 OpenAI 单图总像素上限 8,294,400 限制，**仅支持 6 种比例** |

#### 4K 支持比例白名单

✅ **支持 4K**：`16:9` · `9:16` · `2:1` · `1:2` · `21:9` · `9:21`

❌ **不支持 4K**（脚本会自动降级为 2K）：
| 比例 | 降级原因 |
|------|---------|
| `1:1` | 3840² = 14.7M > 8,294,400 像素上限 |
| `3:2` · `2:3` | 3840×2560 = 9.83M > 上限 |
| `4:3` · `3:4` | 3840×2880 = 11.06M > 上限 |
| `5:4` · `4:5` | 3840×3072 = 11.80M > 上限 |

### Size 参数对照

| 场景 | 比例 | 推荐分辨率 | 用途 |
|------|------|-----------|------|
| Profile 更新帖封面 | `4:5` | **2k** | 小红书/X/微信状态帖 |
| X 帖子配图 | `16:9` | 2k 或 **4k** | 横向叙事图 |
| 头像/Icon | `1:1` | **2k** | 头像/品牌标识 |
| 故事/海报 | `3:4` | **2k** | 竖向海报 |
| 品牌横幅 | `2:1` | 2k 或 **4k** | X header / 网站横幅 |
| 电影感超宽屏 | `21:9` | 2k 或 **4k** |  cinematic 封面 |

### 输出文件

脚本自动创建文件夹：`~/HermesWork/x-posts/20260423-前缀名/`

每个文件夹包含：
- `{prefix}_{timestamp}.png` — 图片
- `{prefix}_{timestamp}.prompt.txt` — 提示词存档
- `{prefix}_{timestamp}.share.md` — 分享帖文案模板
- `{prefix}_{timestamp}.check.md` — **分辨率质量检查报告**

### 使用示例

```bash
# 日常配图（4:5，2k 默认）
python3 scripts/generate-and-share.py "极简深色科技卡片" 4:5 tech-card

# 高清海报（3:4，2k）
python3 scripts/generate-and-share.py "收藏版叙事海报" 3:4 poster 2k high

# 超宽屏横幅（21:9，4k）—— 4k 可用
python3 scripts/generate-and-share.py "cinematic 品牌横幅" 21:9 banner 4k high

# 正方形头像（1:1，脚本自动降级为 2k，因为 1:1 不支持 4k）
python3 scripts/generate-and-share.py "品牌头像" 1:1 avatar 4k
# → 输出：⚠️ 1:1 不支持 4K，自动降级为 2K
```

### 分辨率检查报告

出图后脚本自动用 Pillow 检查图片实际分辨率，生成 `*.check.md`：

```markdown
# 出图质量检查

## 分辨率验证
✅ 分辨率检查通过：2048×2560，约 5,242,880 像素

- 实际尺寸：2048×2560
- 总像素：5,242,880
- 最大边长：2560
- 预期档位：2k
- 图片格式：PNG
- 色彩模式：RGBA
```

如果检测到分辨率异常，报告会标记 ⚠️ 或 ❌。


## Step 5：高级控图技巧

### 迭代控制

| 迭代方向 | Prompt 写法 | 示例 |
|---------|-------------|------|
| 更像本人 | 明确视觉锚点 + 精神肖像定位 | "圆框眼镜、三七侧分短发、冷静气质" |
| 更高级 | 增加留白、减少元素、统一色温 | "增加留白 20%、只保留 3 个核心叙事元素" |
| 更像品牌主视觉 | 3/4 侧面、边缘光、杂志封面感 | "设计杂志封面感、rim light 分离主体与背景" |
| 更大世界观 | 内部微缩景观叙事密度 | "头部区域为决策宇宙、颈部为协作网络" |

### 常见坑

- **size 用像素字符串会报错**：必须用比例（如 `"4:5"`），不能用 `"1024x1536"`
- **不轮询直接拿图**：任务是异步的，必须轮询 `/v1/tasks/{task_id}`
- **返回 URL 有过期时间**：下载需立即执行
- **高质量 = 慢**：ultra quality 可能需要 60-90 秒

## Step 6：信息抓取（从 X/Twitter 获取优质 Prompt）

### 方法一：浏览器 Console 提取法（推荐，已验证对 X 有效）

当 X 帖子是长文（X Articles 格式）时，直接用浏览器自动化 + console 提取全文：

```javascript
// 在页面 console 中执行
document.body.innerText
```

**优势**：
- 无需第三方服务
- X 的反爬不检测浏览器自动化
- 可以提取完整的 Articles 长文内容
- 返回纯文本，直接可做 knowledge ingestion

**实操步骤**：
```bash
# Hermes 中使用 browser 工具:
# 1. browser_navigate 打开 X 帖子 URL
# 2. 页面加载完成后，browser_scroll 向下翻页确保内容加载
# 3. browser_console 执行 document.body.innerText.slice(0, 50000)
# 4. 拿到完整文本后存档到 HermesWork/
```

### 方法二：AnyCrawl 三引擎方案

当需要批量抓取多个 URL、提取结构化数据时，使用 AnyCrawl：

```bash
# 安装与部署
$ git clone https://github.com/any4ai/anycrawl.git && cd anycrawl
$ docker compose up -d

# 单页抓取（静态 HTML）
$ curl -X POST https://api.anycrawl.dev/v1/scrape \
  -H 'Authorization: Bearer ***' \
  -d '{"url": "https://x.com/MrLarus/status/2046627021674168640", "engine": "cheerio"}'

# JS 渲染页面抓取
$ curl -X POST https://api.anycrawl.dev/v1/scrape \
  -H 'Authorization: Bearer ***' \
  -d '{"url": "URL", "engine": "playwright"}'
```

### 方法三：Jina AI Reader（最快单页，无需 API Key）

```
https://r.jina.ai/http://URL
```

**局限**：
- 只能抓单页
- 不支持 JS 渲染（X 的帖子内容抓不到）
- 只适用于纯 HTML 页面

### 抓取方案选择

| 场景 | 推荐方案 | 原因 |
|------|----------|------|
| X 单篇长文帖子（Articles） | 浏览器 console 法 | X JS 渲染，console innerText 可完整提取 |
| 批量抓多个 URL 的文章 | AnyCrawl Playwright | 支持 JS 渲染 + 批量 |
| 纯 HTML 博客/新闻/文档 | Jina AI Reader | 无需 API Key，最快 |
| 需要结构化提取 JSON | AnyCrawl json_options | LLM 结构化提取 |

## Step 7：优质 Prompt 模板库

### 模板 1：轮廓宇宙 / 收藏版叙事海报（来自 @MrLarus）

**结构**：巨大侧脸剪影 → 内部自然生长世界观 → 史诗感/神圣感

**Prompt 核心**：
```
请根据【主题：xxx】自动生成一张高审美的"轮廓宇宙 / 收藏版叙事海报"风格作品。

画面的核心不是简单把世界装进某个物体里，而是让完整的主题世界自然生长在这个主轮廓之中、之内、之上、之边界里或与其结构融为一体。

要求：
- 主轮廓：清晰、优雅、有辨识度（可选：侧脸/门/楼梯井/面具/镜面/王座等）
- 内部世界：丰富饱满、层次清晰、有命运感和情绪张力
- 风格：收藏版电影海报构图 + 梦幻水彩 + 纸张印刷品气质
- 禁止：简单拼贴、素材堆叠、模板化背景、游戏宣传图感、过度卡通
- 色彩：由 AI 根据主题自动判断，但必须低饱和、高级、统一
- 第一眼有轮廓记忆点，第二眼有叙事世界，第三眼有余味
```

## 生成后必做

1. 视觉校验：人物气质、轮廓、色彩是否达标
2. 尺寸校验：目标平台的裁切安全区
3. 压缩：Web 用 PNG/JPG < 500KB
4. 命名规范：`{date}_{type}_{subject}_{variant}.png`
5. 提示词存档：每次生成的 prompt 都要保存，方便复用和迭代
6. 分享帖生成：每次生成图后，配套写出分享帖文案草稿
