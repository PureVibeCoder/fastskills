# Claude Skills 入门：10 个让 AI 更好用的技能

你有没有过这种体验？

让 Claude 帮你写个邮件，它给你来了一段四平八稳的官样文章。让它做个 PPT 大纲，干巴巴的几条要点。让它写个报告，通篇"一方面...另一方面..."的废话。

不是 Claude 不够聪明。问题是——你没告诉它**怎么做**。

这就是 Skills 要解决的问题。

---

## Skills 是什么？

简单说：**Skills 就是一份说明书，告诉 Claude 怎么做某类事情。**

打个比方。你新招了个实习生，很聪明，但啥也不懂。你让他写份报告，他会写，但格式乱七八糟。你给他一份"报告写作指南"，告诉他标题怎么起、结构怎么排、引用怎么标——他马上就能写出像样的东西。

Skills 就是这份指南。只不过它是写给 Claude 看的。

GitHub 上有很多开源的 Skills，覆盖写文档、做调研、做 PPT、写论文等各种场景。你可以直接拿来用，也可以自己写。

接下来我介绍 10 个最值得尝试的技能。不管你是上班族、学生、创业者还是自媒体，总有几个能用得上。

---

## 1. 头脑风暴 (Brainstorming)

**场景**：你有个模糊的想法，但还没想清楚具体要什么。

普通的 Claude 会直接开干——你说"帮我写个活动策划方案"，它二话不说就开始写。结果写完你一看：不是我想要的。

加载"头脑风暴"技能后，Claude 会先问你一堆问题：

- 这个活动是给谁办的？
- 预算大概多少？
- 有什么必须包含的环节？
- 有没有参考案例？

一次只问一个问题，等你回答完再问下一个。这种"先想清楚再动手"的方式，能帮你避免大量的返工。

---

## 2. 文档协作 (Doc Co-Authoring)

**场景**：你和 Claude 一起写了份文档，但担心别人看不懂。

这个技能有个很妙的机制叫**读者测试**。

写完文档后，技能会启动一个"新的" Claude（没有任何上下文），让它读你的文档，然后回答几个预设的问题。如果这个新 Claude 答不上来，说明文档有盲点。

这就像你写完邮件后，找个完全不了解背景的同事帮你看一眼："这封邮件你看得懂吗？"

我写方案的时候特别爱用这个技能。以前经常出现"我写得很清楚，领导一看全是问号"的情况。有了读者测试，发出去之前就能发现大部分问题。

---

## 3. 内部沟通 (Internal Comms)

**场景**：你需要写周报、公司新闻稿、项目更新，但不知道怎么写得专业。

这个技能提供了一整套企业内部沟通的模板：

- **周报 (3P Update)**：Progress（进展）、Plans（计划）、Problems（问题）
- **公司新闻稿**：标准的企业公告格式
- **项目更新**：给利益相关方的进度汇报
- **FAQ 文档**：常见问题解答的标准结构

对于办公白领、行政人员来说，这个技能能帮你省下大量琢磨格式的时间。拿起来就能用，写出来的东西看起来也更专业。

---

## 4. 深度研究 (Research Executor)

**场景**：你需要认真调研一个主题，不是随便问问。

普通 Claude 做调研，你问它"新能源行业现在怎么样"，它会给你一段泛泛的介绍，说一些"发展迅速、前景广阔"的废话。没有来源，没有数据，没有深入分析。

深度研究技能完全不一样。它会执行一个 7 阶段的研究流程：

1. 界定问题边界（你到底想知道什么）
2. 分解子主题（把大问题拆成小问题）
3. 并行派出多个"研究员"去找资料
4. 交叉验证结果
5. 综合成报告
6. 检查引用质量
7. 打包输出

其中第 3 步很有意思——它会同时启动多个子任务：几个去搜网页、一两个去找行业报告、一个专门做事实核查。

最后所有来源会按可信度分级（从权威机构报告到网友评论都标清楚），你能清楚看到每个结论的支撑有多强。

---

## 5. 市场研究报告 (Market Research Reports)

**场景**：你需要一份专业的市场分析报告。

这个技能能生成麦肯锡风格的研究报告，50 页以上，包含：

- 执行摘要
- 市场规模分析（TAM/SAM/SOM）
- 波特五力分析
- PESTLE 分析（政治、经济、社会、技术、法律、环境）
- 竞争格局
- 风险评估
- 战略建议

还会自动生成可视化图表：市场增长曲线、竞争矩阵、风险热力图。

对于创业者、投资人、战略规划者来说，这是省钱又省时的利器。当然，AI 生成的报告有局限——数据可能不够新，分析深度比不上真正的行业专家。但作为初稿或框架，已经非常够用了。

---

## 6. Excel 专家 (XLSX)

**场景**：你需要做数据表格，但不太会用复杂的 Excel 功能。

这个技能不只是帮你填数据，而是像一个 Excel 高手一样帮你：

- 自动生成公式（VLOOKUP、SUMIF、透视表）
- 设置条件格式（数据越大颜色越深之类的）
- 创建专业图表（柱状图、折线图、饼图）
- 做财务建模（收支预测、ROI 计算）

你只需要用自然语言描述你想要什么："帮我做一个按月份统计销售额的表格，高于平均值的用绿色标出，低于平均值的用红色标出，最后加一个趋势图。"

它就能给你生成一个完整的、专业的 Excel 文件。

---

## 7. PPT 专家 (PPTX)

**场景**：你要做汇报，但做出来的 PPT 总是很丑。

这个技能内置了多种专业配色方案和布局策略。你可以：

- 从零开始生成 PPT（给个主题就行）
- 基于现有模板填充内容
- 优化已有 PPT 的视觉效果

它特别擅长的是**结构化内容的视觉呈现**——比如把一段长文字变成要点清晰的幻灯片，把数据变成直观的图表，把流程变成步骤图。

对于经常需要做汇报的人来说，这个技能能大幅减少"做 PPT"的时间，让你把精力放在内容本身。

---

## 8. 科学写作 (Scientific Writing)

**场景**：你要写学术论文或技术文档。

这个技能让 Claude 按学术规范来写：

- 正确的引用格式（APA、MLA、Chicago 等）
- 规范的图表标注
- 严谨的逻辑结构
- 适当的学术用语

对于科研人员、研究生、学术工作者来说，可以大幅提升写作效率。它不只是帮你写，而是确保写出来的东西符合期刊投稿标准。

还有配套的**文献综述**技能，能自动总结大量论文的核心观点，对比不同来源的异同。

---

## 9. 知识管理 (Obsidian Bases)

**场景**：你用 Obsidian 做笔记，但知识库越来越乱。

如果你是 Obsidian 用户，这个技能能帮你：

- 设计合理的目录结构
- 优化双链引用（[[这种链接]]）
- 配置数据库视图
- 管理文档属性

Claude 理解 Obsidian 的工作方式，能够帮你把散乱的笔记整理成可检索、可连接的知识网络。

不用 Obsidian 的话，这个技能的思路也适用于其他笔记软件——核心是"如何把信息组织成可复用的知识"。

---

## 10. 创意设计 (Canvas Design)

**场景**：你需要做海报、视觉素材，但不会用设计软件。

这个技能通过文字描述生成视觉设计：

- 活动海报
- 社交媒体配图
- 简单的排版设计
- 数据可视化

你描述你想要的风格、元素、配色，它就能生成对应的设计。虽然比不上专业设计师，但对于自媒体、内容创作者来说，能快速产出"够用"的视觉素材。

## 怎么开始用？

最简单的方式：

1. 在 GitHub 上找到你感兴趣的技能（搜索 "Claude skills" 或 "Claude Code skills" 能找到很多开源项目）
2. 把技能文件的内容复制到你的 CLAUDE.md 里
3. 开始使用

大部分技能都是即插即用的，不需要复杂配置。

## 最后说两句

Skills 的价值不在于让 Claude 做更多事，而在于让它**按正确的方式做事**。

头脑风暴技能的价值是让 Claude 先问清楚再动手。
文档协作技能的价值是让 Claude 用读者视角检验写作。
深度研究技能的价值是让 Claude 像分析师一样做调研。

这些"流程"才是真正值钱的部分。

试试看，你会发现 Claude 其实比你想的更有用——只是之前没人告诉它怎么做。
